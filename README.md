# 《十小咒》互動背誦與校訂研習系統

本專案為大乘佛教漢傳日常課誦必備之「十小咒」互動學習、背誦修持與文字音讀校訂系統。全面對齊 CBETA 中華電子佛典協會原典底本，並融入現代網頁技術與多維度修持功能。

- **線上體驗網址**：https://ddm-ten-mantras.surge.sh
- **本地工作目錄**：`c:\000prajna\十小咒\` 與 `c:\000prajna\隨身佛學\public\mantras\`

---

## 專案緣起與核心原則

1. **嚴謹對齊 CBETA 原典**：
   經文底本、譯者出處與大藏經編號均嚴格考證自 CBETA（T19、T20、T21 等密教部經典），經意解說依循《佛光大辭典》與印順導師著作，不虛構、不妄改。
2. **文字與音讀並重（精確校音）**：
   真言陀羅尼重在音聲相應與意持。系統提供「經文國字校正」、「注音即時轉通用拼音」雙向對齊功能，支援針對特定寺院課誦傳承（如法鼓山、佛光山、萬佛聖城等傳統音讀）進行字音微調並持久化儲存。
3. **護眼美學與無障礙設計**：
   嚴格遵守護眼配色規範，採用「暖日微沙（羊皮紙微黃）」與「曜石暖暗（禪意夜讀）」雙模式切換，杜絕高刺激螢光色與生硬純白。
4. **防禦性本機運行架構**：
   全站採用原生純 HTML5 / CSS3 / JavaScript，不依賴龐大框架。實作 `SafeStorage` 安全快取機制，雙擊本機 `file:///` 即可直接完整離線運行，不受跨域或儲存權限異常崩潰影響。

## 系統核心功能模組

### 一、 三大首頁瀏覽佈局（多重視角引導）
使用者可自由於首頁切換適合的瀏覽維度：
1. **九宮精靈卡片 (Grid Cards)**：
   - 展現 10 部小咒之標題、出處經本、譯者、修持功德與經典核心摘要。
   - 支援「全部顯示」、「每日早晚課常誦」、「懺悔解厄」、「智慧往生」分類標籤快篩。
2. **經典傳承列表 (Classic List)**：
   - 傳統經目列表風格，清晰呈現編號、漢語音節長度、句數與功德綱要。
3. **經義功德矩陣 (Wisdom Table)**：
   - 比較分析表格，一覽十小咒的修法主尊、原典藏號（CBETA No.）、功德利益與修習相應指引。

---

### 二、 三大內頁閱讀視角（文意音三位一體）
進入單一咒語後，提供三種對照閱讀模式：
1. **三音展卷模式 (Tri-Layer Reading)**：
   - 經典直覺的「上拼音、中注音、下國字」三層垂直堆疊。
   - 具備全形標點分離與分行斷句，字字整齊對齊。
2. **雙欄直排閱讀 (Split Parallel View)**：
   - 左欄為繁體經文原典，右欄為白話消文、梵義析解、經本出處與修持要領，邊讀邊明瞭深義。
3. **分句研習卡片 (Sentence Cards)**：
   - 將整部真言切為呼吸節奏之短句卡片，提供單句反覆熟讀、遮蔽測驗與發音提示。

---

### 三、 三大實戰修持輔助模式

1. **逐字高亮／呼吸節奏導讀 (Chanting Companion)**：
   - 點擊「開始念誦」後，字音依呼吸拍拍律動（支援 0.75x、1.0x、1.25x 速度調整）。
   - 沉浸式金色柔光游標逐字移動，引導攝心專注、不疾不徐。
2. **遮蔽記憶與默寫驗證 (Cloze & Recitation Check)**：
   - **遮蔽注音／拼音**：保留國字，考驗自身音讀熟練度。
   - **全遮蔽／隨機遮蔽 30%**：考驗經文記憶，點擊空白可翻開提示。
   - **實戰打字／默寫比對**：提供即時輸入框，與標準底本即時 Diff 比對，自動以紅綠色標記錯漏字與缺漏標點。
3. **念誦計數器與定課紀錄 (Chant Counter & Logs)**：
   - 支援點擊木魚、空白鍵（Space）或行動裝置觸控計數。
   - 具備每達 7 遍、21 遍、49 遍、108 遍之圓滿柔和音效與微震動反饋。
   - 本地 SafeStorage 自動累計今日功課與歷史總數。

---

### 四、 經文國字與音讀自訂校正系統（含拼音即時互換）

為解決各寺院早晚課傳統唸法差異（如「唵」讀 ㄢ 或 ㄨㄥˇ、「耶」讀 ㄧㄝˊ、「篅」讀 ㄖㄨㄟˋ 等）：
1. **互動校訂面板**：
   - 進入咒語頁點擊「✏️ 校訂字音／國字」，即可開啟即時校訂視窗。
   - **國字修改**：第一欄國字提供輸入框，可直接校訂字體或正異體字。
   - **注音輸入即換算拼音**：在第二欄輸入注音符號（如 `ㄧㄝˊ`），系統內建聲韻母規則自動換算帶聲調之漢語／通用拼音（如 `yé`）並自動填入第三欄，免去特殊帶調英文字母輸入之困擾。
2. **永久寫入官方底本機制**：
   - 提供「📋 複製目前修改給 AI 固化」按鈕，產出 JSON 結構，可直接由助理寫入 `mantras.js` 成為底本。
   - 已為第一咒《如意寶輪王陀羅尼》永久寫入修正音（「耶」`ㄧㄝˊ`/`yé`、「唵」`ㄢ`/`ān`、「斫」`ㄗㄨㄛˋ`/`zuò`、「缽」`ㄅㄛˇ`/`bǒ`、「篅」`ㄖㄨㄟˋ`/`ruì`、「阿」`ㄛ`/`ō`、「吽`ㄏㄨㄥˋ`/`hòng`、「跋」`ㄅㄚˊ`/`bá`、「亶」`ㄉㄢˇ`/`dǎn` 等）。

## 快速開始與使用方式

### 1. 本地直接運行（零依賴）
本專案為純靜態前端應用，無需安裝任何後端伺服器或 Node.js 環境：
- 直接在檔案總管中雙擊開啟 `index.html`（支援 `file:///` 協定）。
- 內建 `SafeStorage` 防禦快取，在本機檔案協定下會自動降級記憶體安全儲存，確保不受瀏覽器安全性原則影響而拋出例外。

### 2. 部署至 GitHub Pages
1. 在 GitHub 上建立全新公開 Repository（如 `ten-mantras`）。
2. 在本機目錄執行：
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of ten mantras v1.8"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/ten-mantras.git
   git push -u origin main
   ```
3. 進入 GitHub Repository 的 **Settings** -> **Pages**，將 Source 設定為 `main` 分支根目錄 `/ (root)` 即可自動上線。
